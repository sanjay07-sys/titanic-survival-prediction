# Titanic Survival Prediction

A simple machine learning project predicting passenger survival on the Titanic using Scikit-learn.

## Approach
- Used the Titanic dataset (Seaborn)
- Cleaned missing age values and encoded categorical features (sex)
- Trained a Decision Tree Classifier
- Achieved 79.89% accuracy on the test set

## Tools
Python, Pandas, Scikit-learn, Google Colab
